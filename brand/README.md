# Brand

## The mark

A cat in profile above a laurel wreath, with a small four-pointed star at
its foot. Navy ink, a cream ground and gold leaf.

| File | Use |
|---|---|
| `logo/catvinci-logo-original.png` | The original artwork with the CatVinci Studio wordmark (1254 × 1254). |
| `logo/catvinci-mark.png` | The mark alone, cropped from the original, on its own paper. |
| `logo/catvinci-mark-on-paper.png` | The same with the paper lifted to pure white, for `mix-blend-mode: multiply` on a light page - the white takes the page's colour. |
| `logo/catvinci-mark-600.png` | The website's size of the above. |
| `logo/catvinci-mark-square.png` | Square, padded, on paper (1024 × 1024): the source for avatars and icons. |

| `icons/catvinci-avatar-512.png` | Avatars (GitHub's limit is 1 MB; this is 134 KB). A JPEG and a 256 px version beside it. |
| `icons/catvinci-mark-{32,64,180,512}.png` | Favicon, apple-touch-icon and app sizes. |

**Don't** place the plain mark on a dark ground: its white separating lines
are the paper showing through, and on dark they disappear. Use the badge.
There is no transparent version of the mark for the same reason.

## Type

One family throughout, as on the Textus site: **Cormorant Garamond**, with
**Noto Serif SC / TC / JP / KR** for Chinese, Japanese and Korean. No
sans-serif. Display sizes light (400); text 500 and never below about
18 px; labels in its small capitals (`font-variant: all-small-caps`).
Cormorant's figures are old-style by default - set `lining-nums` in
headings, or "1.0" reads as "I.o".

## Words

- Name: **CatVinci Studio** in full; **CatVinci** alone as the website's
  wordmark.
- Positioning: *An open-source organization making AI useful to everyone.*
  - 一个开源组织，让 AI 为每个人所用。
- Motto: *Per aspera ad astra* (always upright, one style for the whole
  line), glossed *Through hardship, to the stars.* - 循此苦旅，以达天际。
- Support line: *Supported by the Anthropic Startup Program.*
